# Contribution policy: Vakyartha

Vakyartha is developed and maintained by Nisheeth Ranjan. External contributions are not accepted.

Please do not submit pull requests or patches, including changes to code, documentation or translations. Unsolicited contribution pull requests will be closed without review. Maintain your changes in your own fork.

This is a repository maintenance policy, not an additional license condition. You may use, copy, modify, distribute and sell the software under the terms of the [MIT License](LICENSE), including maintaining and publishing your own fork. There is no obligation to contribute changes back.

For security vulnerabilities, follow the private reporting guidance in [SECURITY.md](SECURITY.md).

Framework issues belong to [Projection](https://github.com/nranjan2code/Projection), under the same policy.
