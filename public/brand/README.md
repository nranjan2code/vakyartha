# Vakyartha identity

The Vakyartha Songbird, full-name outlined wordmark and platform icons are copied unchanged from `~/Projects/Vak/code`, commit `61729cb0f4bbd02fe7f935c787c934cc39123477`.

- `songbird-*.svg` and `wordmark-*.svg`: `crates/vak-client-ui/public/assets/brand/`.
- `lockup-*.svg` and `../icon.svg`: `docs/brand/exports/` (the icon is `vakyartha-app-icon.svg`).
- `../../src-tauri/icons/`: `crates/vak-desktop/icons/`; `tray-template.png` is copied as `tray.png`.

Use the complete Vakyartha name. The Songbird has a swept crest, an open V-shaped wing and a saffron throat. Indigo ink is `#101D3D`, saffron is `#F5A400`, and warm paper is `#F6F5F1`. The sidebar uses the outlined wordmark as a mask with ink/paper colors for light/dark mode. The wordmark is outlined, so it needs no Manrope runtime; `OFL-Manrope.txt` preserves that font's license. The interface text uses Inter 4.1 (variable, bundled in `public/fonts/`, license `OFL-Inter.txt`).

The source project's MIT license does not license the Vakyartha name, Songbird logo, character designs or artwork. Third-party material retains its own license. These assets are used here as Vakyartha's identity at the owner's direction.

For artwork changes, update the original SVG masters and regenerate in the source project, then copy the corresponding exports together. Do not hand-edit generated artwork here.
