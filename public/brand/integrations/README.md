# Integration identity assets

These unmodified publisher marks identify their corresponding services in the catalog. They do not indicate endorsement or change an integration's trust/access policy. Other app capability icons remain original artwork in `src/icons.ts`.

`provenance.json` records the source/resolved URL, retrieval date and SHA-256 of each asset. MCP's mark comes from the protocol project's documentation favicon; GitHub's mark comes from its official logo assets; Docker's Moby mark comes from its official site. Curated service avatars come from the matching publisher's public GitHub organization metadata, not a logo aggregation service. No brand code, SDK or font is included.

Marks remain the property of their respective owners. Use is limited to identification of the named service. Brand guidance: [GitHub](https://github.com/logos), [Docker](https://www.docker.com/company/newsroom/), [MCP documentation source](https://github.com/modelcontextprotocol/docs). MCP documentation's [license](https://github.com/modelcontextprotocol/docs/blob/main/LICENSE) applies to its source assets; trademark rights remain separate. The original protocol documentation license is retained alongside its mark.

External directory listings use their supplied icon metadata through the app's authenticated public-image proxy; they are not downloaded into this source asset directory. Unsupported/missing images use publisher initials.
