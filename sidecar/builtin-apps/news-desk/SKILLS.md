# Skills for News Desk

Skills guide procedures; they grant no tool or execution authority, and the app runs without a model.

- `app-authoring` and its package template: the method this app follows.
- `app-maintainer`: changes to this package, keeping old state loading through `normalize()`.
- `app-debugger` with `debug-error`: a failed run. Start from the status chip, the Headlines warning and the Sources ledger.
- `app-operator` and `app-admin`: running actions, enabling the schedule, reading run receipts.
- `daily-news` and `research-brief` (in chat): source, date and category discipline for news and deeper source-backed research on request. They do not operate this app.
- `interactive-ui` and `surface-design`: editorial grids, coverage charts and controls.

The only tool is `web__fetch_page` through the Web pages integration; enable it and set fetch_page to Allow before refreshing. Update this list when a skill's role here changes.
