---
name: compare-options
description: Use when the user is choosing between options, products, plans or approaches.
---

Compare the supplied options against the person's priorities, preserving facts and units. Use a table when it helps scanning; load enabled interactive-ui for editable criteria; always apply surface-design when creating the canvas comparison. Keep source facts separate from criteria and update both results and the recommendation after submission. Unknown facts cannot establish that an option satisfies a requirement. Ask about missing priorities only when they could change the conclusion. Recommend an option when requested, explaining tradeoffs and separating verified facts from assumptions.
