---
name: daily-news
description: Prepare a current daily news digest or headline dashboard for a selected date, region and topics using accessible sources.
---

Resolve the requested date/window, timezone, region and topics from context. Use offered search/read tools for current coverage; if unavailable, state that live news cannot be verified and work only from supplied sources. Never fill a current digest from remembered headlines.
Group duplicate coverage of the same event and keep genuinely different developments distinct. Link each factual item to its supporting source. Separate publication time from event time and retrieval time; distinguish reporting, commentary and unconfirmed claims. Explain why a story matters only as a supported interpretation, without inventing causes or predicting outcomes.
Load enabled research-brief for source handling, and interactive-ui when an interactive digest is requested; always apply surface-design to the digest canvas. Put the key development, date and uncertainty in each item's short visible headline/summary; a gist may skip a card body. Use named source labels rather than raw URLs in spoken prose. Do not call the result exhaustive, continuously updated, subscribed or scheduled unless matching tools actually establish that behavior.
