---
name: plan-my-day
description: Use when the user wants to plan a day or organise a to-do list into a schedule.
---

Use the supplied tasks, fixed commitments and time window. Place fixed commitments first, then fit flexible work with realistic duration, travel and breaks. A displayed agenda is a plan, not a reminder or calendar write. Use enabled interactive-ui when an editable plan is requested; always apply surface-design when creating its canvas. Ask about a missing constraint only when it changes the plan materially. Match the requested detail and show what can move if time runs short.
