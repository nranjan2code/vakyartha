---
name: task-tracker
description: Create or revise a personal or team work tracker with statuses, owners, deadlines and blockers; use plan-my-day for time-blocking a single day.
---

Preserve supplied task identities, status, owners and deadlines; leave missing assignments explicit. Track the requested work, not an invented project plan. Use a table or checklist, or a board only when the offered catalog supports it. Load interactive-ui when enabled for editable tracking; the always-on surface-design guidance applies.
Bind edits to canonical records. Distinguish local status edits from submitted operations such as adding a task, revising a plan or changing an external record. On submit, preserve unchanged tasks and acknowledge the actual changes. Completing a checkbox does not perform the task. Do not claim reminders, recurrence, background monitoring, notifications or synchronization unless the corresponding configured tool actually confirms them. Surface state persists in its chat/task; cross-chat recall requires an available context or memory tool.
